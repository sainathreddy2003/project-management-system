# GSD STATE TRACKER
## Current Phase: Phase 2 (MySQL Schema & Database Driver Setup)

### Tech Stack Alignment
- **Language**: JavaScript (.js / .jsx) exclusively across Web, Mobile, and Backend.
- **Backend**: Node.js + Express.js + mysql2 (connection pool + parameterized queries) + bcryptjs + jsonwebtoken + helmet + cors + express-rate-limit.
- **Frontend**: React + Vite + JavaScript/JSX + Tailwind CSS + Axios + React Hook Form + Recharts + Lucide React.
- **Mobile**: React Native + Expo (JS/JSX) + Expo SecureStore + Axios + React Navigation.
- **Database**: MySQL (`project_management_db`) with foreign key constraints and indexes.
